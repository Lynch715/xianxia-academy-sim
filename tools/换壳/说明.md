# 换壳脚本

2.0 的 `index.html` 是用这里的脚本，从《武侠江湖模拟器》的 `index.html` 一次性换出来的：界面和回合引擎是武侠的，世界、名录、属性、提示词换成云霄仙院。

- `t_*.py`：按段落的替换（外壳、光阴成长、规则、推演约束、落账硬卡、界面文案、开局存档、头像描述）。每条替换都要求原文恰好出现一次，对不上会列出来。
- `xxdata.js` / `roster.json`：七院、四派、灵根、天赋、名录十六人，从 1.x 的 `npcs.json`、`static.json` 整理来的。
- 用法：`python3 transform.py 武侠的index.html`，产物直接写到仓库根目录的 `index.html`。

往后改 2.0 就直接改根目录的 `index.html`，不再走这个脚本。只有武侠那边的底子有大更新、想再合一次的时候才用得上。

## S2 加进来的

- `events_convert.py`：把 1.x 的 82 个学生事件转成 `xxevents.js`（`python3 events_convert.py 归档/1.7.1/src/data xxevents.js`）。换算规则写在文件头上。
- `t_events.py`：院中事件的引擎（抽取、五档判定、记账、事件链、暗线浮现）和接进回合的那几处改动。
