# 玩家方向与随心所欲模式验收

日期：2026-10-04 至 2026-10-05。验收针对当前 `index.html`，未发布到远端。

## 已处理

- 随心所欲模式移除慢热、信任与家底对请求的限制；世界及NPC灵石按明确数额结算，多件赠物、多门功法和技艺逐项处理。普通模式继续保留原有门槛。
- 玩家当前方向、明确偏好、已关闭话题与NPC承诺持久保存，并同时传入世界与NPC提示词。新承诺必须引用玩家原话；资源交付的完成状态须有实际结算证据。
- 面板增加“约定与待办”，提供执行和取消入口。取消后不能被模型擅自恢复，玩家明确重启可恢复；后续安排须报告实际进展。
- 空 `scene.unresolved` 清空旧待办；省略或 null 不清空。了结、取消、长时间无下文的话题被记为关闭，玩家明确重启才继续。
- 拒绝事件关闭，暂时绕开事件进入一个月冷却，不再循环回挂。玩家主动重新参与可重启；固定日历与无关NPC事件不再抢走具体行动。
- 带人名、地点、任务的选项同样去重。剧情纠偏先完成当前行动，连续练功等行动可以继续产生新成果，不强制转场、加新人或制造无关阻碍。
- 明显拒绝、指定灵石不足额、缺少有效承诺记录、已关闭待办复活、高度重复回复会在结算前修订一次；仍未通过则不追加模型奖励，并保留重试入口。玩家明确要求复述时允许重复。
- 突破、炼制等结果提示词改用实际耗时；普通行动继续按天推进。存档升级至 v11，保留原有日期进度、物品、承诺及待办年龄。
