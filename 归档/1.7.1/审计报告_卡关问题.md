# 修仙学院模拟器 · 卡关审计（2026-09-16）

审的是当前 `src/`（和 index.html 一致）。现有测试全绿，但它们绕开了下面这些路径。
方法：真浏览器随机点 150 周 × 三身份 × 有/无模型；无头引擎每身份跑 12–20 局统计；再对可疑点写复现脚本。

---

## 一、真卡死：按钮全灰，只能刷新（已复现）

根因是同一个：`UI.running` 只在 `runWeek` 正常走完时才清掉。事件进行中只要主界面被重画，事件选项就没了，`running` 永远是 true，「推演本周」一直灰着。

| 操作 | 结果 |
|---|---|
| **手机上事件进行中点底部「状态 / 叙事 / 安排」** | 卡死。最可能就是你碰到的 |
| 事件进行中点顶栏「秘境」，进去再出来 | 卡死 |
| 事件进行中在设置里读档 / 导入 / 找回上一局 | 卡死 |
| 事件进行中回标题页再点「继续」 | 卡死 |
| `runWeek` 里任何一处抛异常（没有 try/finally） | 卡死 |

刷新能救回来（有断点续推），但玩家不知道。

**心魔关没选完时点顶栏「推演本周」**：不卡，但 A/B/C 被清掉、改成显示本周事件，这次突破就没了，`_btOpts` 残留在存档里。

## 二、内容永远触发不了（引擎层，已统计）

1. **7 个事件的时段条件永远不满足。** 每周的事件是在周一清晨一次抽完的，那时 `phase` 恒为 dawn，所以写了 `phase: noon/dusk` 的全废：
   `evt_wenjiujiu_stairs`（连带 `evt_wenjiujiu_medicine`，温酒酒早期线整条没了）、`evt_vein_anomaly`、`evt_deviation_neighbor`、`evt_canteen`、`evt_rain_shelter`、`evt_night_practice`。
2. **五条专属感情线被「告白」事件锁死。** `evt_confession_received` 从第 38 周起就能出，一出就设 `confession_handled`；而沈惊澜 / 温酒酒 / 裴无忧 / 叶素素 / 赵鸣岐的第一章都要求没有这个 flag，最早第 42–60 周才开。20 局谨慎玩法里这五条一次都没出现过。
3. **暗线「内鬼」永远不会浮现。** 解锁要 `leak_incident ≥ 2`，全游戏只有一个事件写它，而且是 `set 1`。于是 `evt_zhong_letter` 也永远出不来。进度能涨到 100，但暗线面板不认。
4. **暗线「封印之下」基本解不开。** 要 `lingxu_explored + vein_anomaly ≥ 3`：主要来源 `evt_vein_anomaly` 是上面那个废事件；事件里的 flag 效果是 `set` 不是 `add`，会把秘境、春猎累加上去的数覆盖回 1 或 2。20 局谨慎玩法封印进度全是 0。连带：`evt_pei_reveal`、`evt_lingxu_opening`、`evt_seal_choice`、院主的 `evt_gov_seal_pressure`、隐藏结局「封印守护者」全都走不到。
5. **告白后「婉拒」判定好 → 挂上约会链，但约会要求 `in_relationship`，永远满足不了。** 这条链会一直挂着，「当下要紧」里永远有一句「有件事还没了结」。告白选「说需要时间想想」设的 `confession_pending` 没有任何地方读，是条死路。
6. 教习的 `evt_teacher_student_line` 要的 `forbidden_teacher_romance` 从没被设置过，禁忌之恋结局走不到。
7. 劝退：`expelled_pending` 设上后既不会真劝退，也不会清掉，之后每个月结算都提示一遍「面临劝退」。

## 三、数值墙：怎么玩都到不了

1. **弟子到不了金丹。** 20 局谨慎玩法，筑基后期最早第 143 周；筑基每层要 8000–32000 修为，全排打坐一周大约 300，再加上筑基大圆满突破要扣 32 点成功率。五年到不了金丹，于是：毕业条件 `canGraduate`（要金丹）、「一代天骄」结局都不可达。
2. **教习带不出金丹弟子。** 弟子一周大约长 100 修为，筑基到金丹要 8 万，八年任期不够，「桃李满天下」不可达（自带测试里也一直是金丹 0）。弟子也从来不会毕业。
3. **教习照默认日程玩，大概率一两年内「教学事故」直接结束。** 默认排课下弟子压力每月净涨约 8（正课每节 +1、单独指导 +4，月度只回落 8），能降压的只有指导掷出圆满（−6）。压力 ≥85 连续两个月就可能走火，一出事整局立刻结束。只用自动排课跑 12 局，9 局是这样结束的。另外 `evt_disciple_cheat` 选「按院规交给秦九思」掷出糟糕也会直接触发同一个结局，而文案写的只是「被劝退」。
4. **院主的议事三四周就议完了。** 一共只有 8 个议题，默认一周排两次议事，之后「议事」格子什么都不做，一直空转到第十年。
5. **院主威望只降不升。** 议事议完后，涨威望只剩「外患平息」一条路；外患默认用「交涉」，遇到武力型外患每次都是 −15 修正，进度常年停在 0，每次糟糕判定还扣 1 威望。8 局里威望全部掉到 0，离「众叛亲离」只差人心那一个条件（随机点的 UI 测试两局都是这个结局）。

## 四、看着像卡住的

- 模型超时太长：叙事、自拟行动解析的超时都是 120 秒，解析失败还会重试一次，最坏要等 4 分钟，这期间屏幕上只有转圈的点。对话一轮最坏 2 分钟。
- 学生的固定事件（开学典礼、新生考核、冬至论道、七院大比）不看身份，教习和院主每年也会收到；冬至论道的 `minWeek` 也被跳过了。
- 大比、春猎、交流赛的横幅也不看身份，而且只在当月第二周出现，推过去就错过了，没有提示。
- 日程里排「坊市」这一格什么都不做（`openPanel` 没人接）。

## 修复方案（等你确认再动）

**A. 卡死（优先）**
1. `runWeek` / `playMessage` / `playEvent` 包 try/finally，出错也清掉 `running`，并给一个「出了点问题，本周从断点继续」的提示。
2. 推演中锁住会重画主界面的入口：顶栏修炼 / 坊市 / 秘境 / 设置里的读档、导入、回标题。手机标签页改成只切 CSS 类、不重建 DOM（叙事区原样保留）。
3. 兜底：`render()` 发现 `running` 为 true 但事件选项不在屏幕上时，重新挂出当前事件的选项。
4. 突破流程也算 running，心魔关期间顶栏推演不可点。

**B. 死内容**
5. 时段条件改到插入事件的时候判断（事件落到哪个时段就按哪个时段算），或者直接去掉 `phase` 条件。
6. 五条感情线去掉 `confession_handled` 限制，改成「已有道侣则不开」；或者把告白推迟到第 60 周以后，且只在没有进行中的专属线时出现。
7. 事件的 flag 效果支持 `op: add`，`leak_incident`、`vein_anomaly`、`lingxu_explored` 改用累加；内鬼门槛核一下可达性。
8. 事件链只在选项本身「接受」时挂；链目标事件连续 N 周匹配不上就作废，别一直挂在「当下要紧」里。「想想」给一个后续（几周后对方再来问一次）。
9. 补上 `forbidden_teacher_romance` 的来源，或者删掉这条事件。
10. `expelled_pending`：要么接一个真的劝退听证事件，要么下一次考试不垫底就清掉。
11. 固定事件和节庆横幅加身份过滤，固定事件走一遍 `match`。

**C. 数值**
12. 筑基修为需求下调（初步想法 8000×层 → 2500×层左右），大圆满突破的层数惩罚减半；目标是谨慎玩法第四、五年能结丹、能毕业。先跑 balance 再定。
13. 弟子成长同步调，并加「弟子结业」。
14. 教习：弟子出事改成弟子离开 + 心魔 + 评价扣分，不直接结束整局（同一任期出事两次再终局）；加一个降压手段（比如「放假 / 带弟子出游」活动），默认排课不能自己把人逼出事。
15. 院主：议题做成可以轮换重复（每季度刷新一轮），加一个稳定涨威望的日常行动；外患的默认应对按外患类型选。

**D. 体验**
16. 模型调用超时：叙事 60 秒、解析 25 秒、对话 30 秒；超过 10 秒在转圈旁边显示「模型响应慢，可点此改用内置文本」。
17. 日程「坊市」一格：推演到这里时弹出坊市，或者从活动列表里删掉。

**验收**：把这次的复现脚本（5 个卡死场景）和统计脚本（死事件、暗线可达、境界时间线）收进 `test/`，接进 `npm test`。

## 处理结果（同日，1.2.0）

17 条全部按上面的方案改完，改动清单见 README「1.2 卡关修复」。与方案不同的地方：

- 第 9 条选了删除：师生线事件和「禁忌之恋」结局一起去掉，结局从 23 种变成 22 种。
- 第 13 条：弟子的筑基门槛定为玩家的 2.2 倍，结丹或满五年出师；教学评价「优」的门槛从 82 分提到 90 分。否则「给弟子放假」把压力压下去之后，只用自动排课也能连拿「优」，「桃李满天下」等于白送。
- 第 15 条：例会攒满 6 点涨 1 威望（圆满 +2、好 +1）。
- 第 17 条：日程里直接去掉「坊市」，坊市还是从顶栏进。

复测结果：五种卡死都修好了（test/stuck.js）；六局暗线测试里「内鬼」「封印」每局都浮现了；五局用心修炼的学生五年内都结了丹；院主按默认日程、认真议事，8 局都撑到任期结束；随机点 150 周的真浏览器测试没有卡死，也没有报错。
