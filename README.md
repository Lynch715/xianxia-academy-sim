# 修仙学院模拟器 · 云霄仙院（2.0）

单 HTML 文件。你是云霄仙院这一届的新生，接下来五年都在院里过。故事由你自己的大模型往下推，成败和数值由页面里的引擎记账。

2.0 是一次大改：界面和按月推进的回合引擎整套换成《武侠江湖模拟器》那一套，世界换成云霄仙院。1.x（周制日程、斗法四类相克、炼制、生涯贯通）整体归档，旧版以 `v1.html` 留着，老存档在那里接着玩。

**必须接模型。** 没填密钥只能看一段样张。同一个域名下玩过武侠江湖或 1.x 的，头一回进来会自动借用那边填过的密钥。

## 引擎卡死的东西（模型写什么都不算）

- 学院：开局选定，模型写主角改投别处一概不认。
- 名录里的人：身份、境界、学院、秘密、生死都不收模型的改动；名字一出现在剧情里就按名录带进来，模型冒名编的资料丢掉。新人身份里带「教习、院首、长老、院主」的直接拦掉。
- 修为：一回合的涨幅按悟性、灵根、自由度封顶；到了境界门口（练气九层顶、筑基大圆满顶……）就不再涨，要突破。资质一回合最多 +3。
- 心魔：一回合最多 +8、最多 -4。
- 好感与信任：教习这一级一回合最多 +5；信任一回合最多 +8，面谈里一句最多 +6。秘密只在信任够了（或者套话成功）才算露，模型说「吐露了」不算数。
- 灵石：一回合进项按自由度封顶。
- 突破、炼制、心魔关、院中事件的结果回合：引擎先结算，模型写的数值一概不收。
- 连着两回合在院外，下一回合必须回院。

## 测试

```bash
npm i playwright
PW_CHROME=… node test/run.js     # 假模型跑开局、回合、面谈、斗法、存读档，101 项
SHOT_DIR=/tmp/shots node test/shot.js   # 手机尺寸截图
```

`test/mock.js` 专门往返回里塞越界的东西（改学院、给名录人物改身份、编长老、横财九百、心魔 +15），看引擎拦不拦得住。
