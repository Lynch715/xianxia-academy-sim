# 修仙学院模拟器 · 云霄仙院（2.0）

单 HTML 文件。你是云霄仙院这一届的新生，接下来五年都在院里过。故事由你自己的大模型往下推，成败和数值由页面里的引擎记账。

2.0 是一次大改：界面和回合引擎整套换成《武侠江湖模拟器》那一套，世界换成云霄仙院。1.x（周制日程、斗法四类相克、炼制、生涯贯通）整体归档，旧版以 `v1.html` 留着，老存档在那里接着玩。

**必须接模型。** 没填密钥只能看一段样张。同一个域名下玩过武侠江湖或 1.x 的，头一回进来会自动借用那边填过的密钥。

## 引擎卡死的东西（模型写什么都不算）

- 学院：开局选定，模型写主角改投别处一概不认。
- 名录里的人：身份、境界、学院、秘密、生死都不收模型的改动；名字一出现在剧情里就按名录带进来，模型冒名编的资料丢掉。新人身份里带「教习、院首、长老、院主」的直接拦掉。
- 修为：一回合的涨幅按悟性、灵根、自由度封顶，境界越高越慢（筑基约四成、金丹两成）；到了境界门口（练气九层顶、筑基大圆满顶……）就不再涨，要突破。资质一回合最多 +3。
- 心魔：一回合最多 +8、最多 -4。
- 好感与信任：普通模式教习这一级一回合最多 +5；信任一回合最多 +8，面谈里一句最多 +6。随心所欲模式不以好感、信任和慢热限制玩家要求。秘密只在信任够了（或者套话成功）才算露，模型说「吐露了」不算数。
- 灵石：普通模式按自由度封顶；随心所欲模式按玩家明确数额交付。
- 突破、炼制、心魔关、院中事件的结果回合：引擎先结算，模型写的数值一概不收。
- 普通模式连着两回合在院外，下一回合必须回院；随心所欲模式跟随玩家去向。

PW_CHROME=… node test/full.js     # 整局自动跑到第五学年结业，看结局、结业文书、院史（AVG=1 用平常资质跑）
PW_CHROME=… node test/mobile.js   # 手机五个尺寸，选项、输入框、面谈、炼制、心魔关、结业文书有没有被挡
SHOT_DIR=/tmp/shots node test/shot.js   # 手机尺寸截图
```

`test/mock.js` 专门往返回里塞越界的东西（改学院、给名录人物改身份、编长老、横财九百、心魔 +15），看引擎拦不拦得住。

施工规范_2.0.md   这次改版的规范与施工流程
```

日制推进：普通行动默认一天，每月按30天计；日期显示到日。只有玩家明确选择或输入带具体月数的修炼/闭关行动才跨月，模型的 months 字段不能自行快进。月例、开销仍在跨月时结算，旧存档原有月份兼容。

玩家方向与承诺：世界与NPC提示词共享玩家当前行动、明确偏好、已关闭话题和承诺状态；约定写入存档，面板可赴约或取消。空的待办数组会清空旧待办，字段省略则保留。已拒绝事件关闭，暂时绕开事件冷却一个月，玩家主动参与可重启；日历事件不再抢走无关行动。重复选项不因带人名或任务名而豁免，剧情纠偏沿玩家行为产生新结果。

随心所欲模式的多件赠物、多门功法和技艺逐项结算，指定灵石不按NPC家底截断。明显拒绝、灵石不足额、未记录的后续承诺、已关闭待办复活或高度重复回复，会在结算前要求模型修订一次；仍未通过则提供重试，不追加模型奖励。境界瓶颈、名录身份与斗法结果仍由引擎控制。

补充验收：`npm run test:story`、`npm run test:time`。`npm run qa:story` 启动仅本机的假模型界面验收，打开 `http://127.0.0.1:8953/qa` 点击“运行完整验收场景”；不使用真实密钥。真实模型遵循程度仍取决于所选模型，当前验收覆盖本地引擎与假模型交互。
